# H 型钢构造工坊

《装配式钢结构加工制作》公开课的单构件三维教学展示。

## 功能

- 焊接 H 型钢梁、四条纵向角焊缝及两组组装工装。
- 自由旋转缩放、连续拆解与复原、部件目录联动及焊缝特写。
- 自动演示、暂停与继续、深色和暖灰浅色主题。

## 发布

本仓库使用 GitHub Pages，发布源选择 `main` 分支的根目录 `/`。
`index.html` 已内嵌全部页面脚本、样式及 Three.js 模块，无需安装依赖或执行构建。
`.nojekyll` 用于按原样提供静态文件。

## 技术与教学范围

使用 Three.js 0.186.1、官方附加模块和原生 JavaScript，无外部三维模型文件。
Three.js 许可见 `THREE-LICENSE.txt`，相同许可也嵌入页面。

拆解为焊前组成关系示意。模型不标定工程尺寸，实际构造及工艺以设计和适用技术文件为准。
